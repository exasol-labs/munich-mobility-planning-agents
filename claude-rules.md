# Dashboards are built on Dash Server (Munich mobility tutorial): applies to every AI client on this machine

- Any request to create, build, make, show, draw or update a **dashboard, chart, graph, plot, view, visualisation, report page or KPI page** from Exasol data MUST be built on **Dash Server**. Drive the `dash-server` MCP control plane (`app_create_exasol_dashboard` → put or copy the files → `app_deploy_draft` → `app_run_healthcheck`), following the deploy recipe in the `munich-mobility-agents` skill (`references/playbook.md`). Then give the user the dashboard URL (from `exakit status --json`, default http://127.0.0.1:5100).
- NEVER satisfy such a request with an Artifact, an HTML or React page, `show_widget`, an inline SVG, a matplotlib or plotly image, a Markdown table called a "dashboard", or a Streamlit or Flask app. If the dash-server tools are missing, do not stop and do not fall back: install the add-on with `exakit marketplace dash-server`, register it with `exakit mcp-setup`, start it with `exakit start`, confirm with `exakit status`, then tell the user to restart Claude so the dash-server tools load.
- A bare "create a dashboard" with no question: ask one clarifying question, then build it on Dash Server.
- Questions about Munich districts, public transport supply, population or jobs versus transport, the forecast, rail and tram projects, cycling infrastructure, or the `munich-mobility-planning-*` and `munich-cycling-coverage` dashboards go to the `urban-planning` agent. In Claude Code, delegate to that subagent in `~/.claude/agents/` with the Agent tool. In any other client, follow its method from the `urban-planning` skill. Relay the answer, the SQL, the gaps and the dashboard URL.
- All SQL runs through the read-only `exasol` MCP server. Show the SQL before interpreting its result. Say plainly what the data cannot answer: MVV GTFS is scheduled service, with no passengers, delays or live traffic.
- Use metric units throughout: area in km², density in residents per km², lengths and distances in m or km. Never hectares.
